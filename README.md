# OLC Accelerate 2026 Workshop

This repository contains the participant materials for the OLC Accelerate 2026 session **GitHub Is for Instructional Designers, Too**.

## Start here

- [Open the LMS accordion builder](https://aceverett.github.io/olc-accelerate-2026-workshop/)
- [Open the presentation slides](https://aceverett.github.io/olc-accelerate-2026-workshop/slides/)

## Workshop steps

1. Select **Fork** near the upper-right corner of this repository.
2. Create the fork in your GitHub account. This gives you a safe personal copy.
3. From your fork's main repository page, press the period key (`.`) to open the browser editor.
4. Open `index.html` and make the workshop change.
5. Open **Source Control**, write a short description, and select **Commit & Push**.
6. Return to GitHub and open **Settings → Pages**.
7. Publish from the `main` branch and the `/ (root)` folder.
8. Copy your GitHub Pages URL and link to it or embed it in your LMS.

You cannot damage the presenters' original repository by editing your fork.

## No GitHub account or unable to fork?

Use the [live accordion builder](https://aceverett.github.io/olc-accelerate-2026-workshop/) and copy the generated HTML directly into your LMS.
